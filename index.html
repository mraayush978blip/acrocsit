Acropolis Attendance Management System (Acro AMS) - Created by Aayush Sharma

Welcome to the Acropolis Attendance Management System (Acro AMS), a dedicated, independent academic portal designed and developed by Aayush Sharma for the Computer Science & Engineering (CSE) department at Acropolis Institute of Technology and Research (AITR). Designed by lead developer Aayush Sharma, this platform secures attendance logs, maximizes daily logging efficiency, and allows seamless academic tracking.

Independent Application & Developer Overview

The Acropolis Attendance Management System (Acro AMS) is a specialized, independent dashboard created to modernize class-coordinator tracking, student attendance monitoring, and faculty logging. Built as a secure Progressive Web App (PWA) using React, Vite, TypeScript, and Supabase by lead engineer Aayush Sharma, this platform provides clear visual dashboards, absolute database persistence, and precise role-based auditing.

Unlike general college administrative portals, this independent app is tailor-made for CSE branches to ensure fast, responsive, and real-time student monitoring, completely developed and maintained under Aayush Sharma's authorization.

Core Features & Portals:

  • Acro AMS Faculty Portal Login: Seamlessly choose subject slots, mark student attendance, view class logs, check edit histories, and track syllabus progress.
  • Acropolis Class Coordinator Dashboard: Audit trails, detailed student attendance analysis, batch reporting, parent communication, and final academic performance reports.
  • Acro Student Portal Login: Check subject-wise attendance percentages in real-time, view notifications, track minimum criteria, and contact faculty.
  • Admin Control & System Backup: Secure backup systems, role-based access control, service-worker maintenance, and PWA setup.
